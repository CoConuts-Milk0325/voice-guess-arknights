# 语音猜干员

根据《明日方舟》干员语音猜干员的网页游戏。

## 功能
- 420+ 干员语音数据
- 中文/日文语音支持
- 输入模式（打字）和选择模式
- 挑战模式（20题、计分、总结）
- 星级筛选
- 语音文本显示
- 皮肤语音

## 使用方法

### 本地运行
1. 安装 Node.js (https://nodejs.org)
2. 双击 `start.bat` 或运行 `node server.js`
3. 打开 http://localhost:5173

### 工作原理
- 服务器代理音频请求到 prts.wiki CDN
- 首次播放某条语音：从 CDN 下载并缓存到本地
- 再次播放：直接从缓存读取（秒开）
- 只下载实际用到的音频，不浪费空间

## 架构
- 前端：Vue 3 + Vite
- 后端：Node.js 代理服务器（自动缓存音频）
- 音频来源：prts.wiki CDN（按需缓存）
- 数据来源：prts.wiki
